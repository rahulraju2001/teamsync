TeamSync notification implementation

- Notifications are persisted in MongoDB.
- New notifications are delivered live through Socket.IO.
- Notifications appear in the navbar and can be marked read individually or all at once.
- Task, project, workspace, assignment, comment, and membership activity can generate notifications.
- Deadline reminders use fixed defaults: one day before and on the due date/deadline.
- Overdue tasks and projects generate one notification per deadline value and recipient.
- The scheduler scans on startup and every six hours. Reminder event keys prevent duplicate delivery.
- Task reminders go to the assignee and task creator. Project reminders go to the project owner and workspace Administrators.
- In-app notifications are always enabled. Per-user notification preferences and email notifications are not implemented.
- No notification preferences UI or API is required.
