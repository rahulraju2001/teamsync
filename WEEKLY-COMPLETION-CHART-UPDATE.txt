TeamSync – Weekly Completed-Task Trend

Changes
- Dashboard now displays a 7-day bar chart of tasks completed by day, plus the weekly total.
- Task documents now have a completedAt timestamp.
- Creating a task directly in Completed sets completedAt.
- Moving a task into Completed records the current date/time. Reopening a task preserves its previous completion timestamp; completing it again records the new completion time.
- The chart uses real completedAt values and the browser's local calendar dates.

Important historical-data note
Tasks that were already Completed before this update have no trustworthy completion timestamp. They are intentionally excluded from the chart rather than assigning inaccurate dates. New completions will appear automatically.

Apply
1. Replace/update the project files with this archive.
2. Restart the backend server so the updated Task model and task route are loaded.
3. Restart the frontend development server (or rebuild/redeploy the frontend).

No new dependency or database migration is required. MongoDB will store completedAt on task documents as they are updated. Existing completed tasks remain unchanged.
