TeamSync — Workspace ownership transfer

Files included:
- server/src/routes/workspaceRoutes.js
- src/context/WorkspaceContext.jsx
- src/components/layout/Sidebar.jsx
- src/App.jsx
- src/pages/settings/WorkspaceSettings.jsx (new)

Apply:
1. Stop the frontend and backend development servers.
2. Extract this ZIP into the existing TeamSync project root.
3. Replace the matching files and keep the new WorkspaceSettings.jsx file.
4. Restart the backend and frontend.

Usage:
1. Open the workspace dropdown in the sidebar.
2. Select Workspace Settings.
3. The current owner selects another Administrator and confirms the transfer.
4. The selected Administrator becomes the owner. The previous owner remains an Administrator.
5. The previous owner can then leave, provided another Administrator remains.

If there is no other Administrator, promote an existing member to Administrator from the Team page first.

The Delete Workspace action has been removed from the workspace dropdown and moved to the Workspace Settings page under Danger zone. It remains available to the current owner and uses the existing backend deletion flow with a custom confirmation modal.

No new dependencies or database migration are required.
