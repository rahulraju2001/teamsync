TeamSync custom dialog update

This update replaces the remaining native browser confirm()/alert() dialogs with one reusable, burgundy-theme-aware React dialog component.

Files included:
- src/components/ui/ActionDialog.jsx (new shared component)
- src/components/layout/Sidebar.jsx (workspace leave/delete confirmation now uses the shared component)
- src/pages/team/Team.jsx (remove-member confirmation)
- src/pages/projects/Projects.jsx (delete-project confirmation and failure message)
- src/pages/projects/ProjectDetails.jsx (delete-task confirmation and task/comment/status error messages)
- src/pages/tasks/Tasks.jsx (task status error messages)

Apply the update:
1. Stop the frontend development server.
2. Extract this ZIP into the root of your existing TeamSync project.
3. Allow the included files to replace the matching files. The ActionDialog.jsx file is new.
4. Restart the frontend with npm run dev.

No new dependencies, backend changes, or database migrations are required. The archive does not include .env files, .git, node_modules, or package-lock files.

Validation performed:
- Parsed all 17 JavaScript/JSX source files without syntax errors.
- Searched the frontend source for native window.confirm(), window.alert(), and window.prompt() calls; none remain.
- A full Vite build could not be run in this environment because node_modules are not installed here.
