TeamSync overdue tracking

What is included
- Dashboard now includes an Overdue Projects statistic alongside Overdue Tasks.
- A task is overdue when its due date is before the current local calendar date and its status is not Completed.
- A project is overdue when its deadline is before the current local calendar date and its status is not Completed. This calculation is independent of the project's task completion percentage.
- The Projects page and dashboard project overview show overdue project deadlines in red.
- The Project Details page shows an Overdue badge for an overdue project.
- The All Tasks page and Project Details list/board show overdue task indicators and red due-date styling.

Behavior
- Due today is not overdue; it becomes overdue the following local calendar day.
- Completed tasks and projects are not counted as overdue, even if their dates have passed.
- No task or project status is changed automatically.
- No overdue notifications are sent in this update. Notifications can be added separately if desired.
- No database migration is required; overdue status is calculated from the existing dueDate and deadline fields.
