TeamSync — Project Kanban Board

Included file:
- src/pages/projects/ProjectDetails.jsx

Features:
- Adds List / Board view switching inside each project.
- Board has To Do, In Progress, and Completed columns.
- Supports native HTML5 drag-and-drop between columns; no new package is required.
- Task cards show priority, assignee initials avatar, due date, and comment count.
- Overdue due dates are highlighted.
- List view remains available with its existing filters, sorting, pagination, status selector, and task actions.
- Board cards retain task details, edit, and delete actions where permitted.

Permissions:
- Administrators can move any task.
- Members can move only tasks assigned to them.
- The backend continues to enforce the same permission rules; the UI does not bypass them.

Persistence and real-time behavior:
- Moving a card calls the existing PATCH /api/tasks/:id endpoint with the new status.
- The existing task route saves the status to MongoDB and emits task:changed through Socket.IO.
- The existing WorkspaceContext listens for task:changed and refreshes workspace data, so other connected members see the change.

Apply:
1. Stop the frontend development server.
2. Extract this ZIP into the existing TeamSync project root.
3. Replace src/pages/projects/ProjectDetails.jsx.
4. Restart the frontend.

No backend changes, database migration, or new dependencies are required.
